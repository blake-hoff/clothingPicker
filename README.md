# clothingPicker
This project was created so that I could track my outfit history each day, and eventually use that long history to automatically choose (predict) an outfit for the next day based on variables such as weather or preference ranking. As I was implementing the tracking portion of this project, I realized it would be useful to be able to track other things such as what I eat, or any special event for that day.

Project is live at:
https://blake-hoff.github.io/clothingPicker/

Currently, you can make an account and log in to it; allowing you to add an outfit each day. You can also add in a meal or event. I am currently working on this project and constantly adding features and fixes. At the moment, the prediction feature of this app has been delayed until I find there are no other features remaining to add.
