# Journal-Web-App

**Project is live at -->** [blake-hoff.github.io/Journal-Web-App](https://blake-hoff.github.io/Journal-Web-App/)

## Background
This project was created so that I could track my outfit history each day, and eventually use that long history to automatically choose (predict) an outfit for the next day based on variables such as weather or personal preference ranking. 

As I was implementing the tracking portion of this project, I realized it would be useful to be able to track other things such as what I eat, or any special event for that day.

## Current Features
Anyone can sign up for an account; allowing you to add an outfit each day. You can also add in a meal or event.

### Tech Stack
* **Frontend:** ReactJS — Hosted on GitHub Pages
* **Backend:** Python (Flask) — Hosted on PythonAnywhere
* **Database:** SQLite & SQLAlchemy
* **Authentication:** Flask-JWT-Extended & Werkzeug password hashing

## Future Plans
I am currently working on this project and constantly adding features and fixes. 

At the moment, the prediction feature of this app has been delayed until I fully complete and polish the base features of the application. This feature would allow the server to suggest your next outfit based on weather conditions and past preferences.
